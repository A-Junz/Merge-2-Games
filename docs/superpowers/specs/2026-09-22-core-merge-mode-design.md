# 核心合成模式重构设计

## 目标

将 Cocos Creator 2.4.13 工程改造成“直接进入合成游戏”的核心模式：移除大厅及非核心系统入口，保留合成棋盘、顾客订单经营、等级经验、资源、在线/离线奖励、新手引导、声音设置、广告/分享/平台 SDK 和配置资源加载。

## 已确认范围

### 保留

- 合成棋盘、食物产出、合成链、顾客订单交付。
- 顾客/订单经营流程及金币、经验奖励。
- 等级、经验、等级奖励领取。
- 金币、钻石/代币、经验等资源模型及 HUD 显示。
- 在线奖励和离线奖励。
- 新手引导及合成操作引导。
- 音乐、音效和设置界面。
- 广告、分享、登录、隐私协议和渠道 SDK。
- 配置表、语言表、公共资源、合成资源和音频资源。

### 移除或禁用

- 大厅主界面及大厅按钮入口。
- 家园场景、建筑和装修。
- 主线任务、建筑进度和每日任务。
- 仓库/冰箱。
- 商店、市场和商品刷新。
- 周期活动、特殊任务、砸蛋、幸运转盘、神秘宝箱、礼包等入口。
- 剧情、对话和大厅对话入口。
- 产品层红点提示。
- 能量资源、能量自动恢复、能量购买、能量购买广告和 CD 加速。

底层事件总线不会整体删除，因为棋盘、食物、顾客订单和资源 HUD 仍需要内部事件同步；删除的是面向被移除功能的产品事件和红点逻辑。

## 启动流程

现有流程是 `Main -> LobbyC -> LobbyView -> GameC`。改造后为：

`Main -> 核心资源/配置加载 -> 隐私/登录 -> GameC -> GameView`

`LobbyC` 可以继续作为兼容性的加载协调器，但不得创建 `LobbyView`，也不得初始化场景、任务、市场、仓库、特殊活动等模块。

启动时需要保留：

- `game_info`、`game_lang_zh`、`activity_info` 等仍被核心玩法使用的配置。
- 公共、合成、音频资源分包。
- `CMgr.helper.startGame()`、登录、隐私协议和广告 SDK 初始化。
- `ActivityMgr`/`ActivityC` 的在线/离线奖励初始化。

## 合成界面设计

`GameView` 作为首屏主界面，继续承载现有棋盘和顾客订单区。

顶部/左上角只保留：

- 等级入口：显示当前等级，点击打开等级奖励界面。
- 设置入口：打开音乐/音效设置。
- 核心资源 HUD：保留金币、代币和经验数值显示；不再显示能量。

以下按钮和节点不应再可见或可交互：

- 场景/建筑。
- 任务和每日任务。
- 商店/市场。
- 仓库/冰箱。
- 特殊任务、砸蛋、转盘、宝箱、礼包、更多游戏等。
- 能量购买和 CD 清除。

顾客订单区域继续使用现有 `BuyView`，不改变顾客需求、食物交付、金币奖励和顾客离场流程。

## 系统边界

### 保留的核心服务

- `FoodMgr`、`GridFoodMgr`、`GameManager`。
- `BuyMgr`、`BuyPerson`、`PersonMgr`。
- `ItemMgr`、`BagManager`，但不再注册或显示能量资源。
- `LevelMgr`、`LevelC`。
- `ActivityMgr`、`ActivityC`。
- `SoundMgr`、`SoundC`。
- `GuideMgr` 及合成引导相关类。
- `SDKManager`、`CMgr` 和渠道广告/分享能力。

### 不再初始化或不再暴露入口的服务

- `SceneMgr`、`SceneC`。
- `TaskMgr`、`TaskC`、`DailyTaskMgr`、`DailyTaskC`。
- `MarketMgr`、`MarketC`。
- `StorageMgr`、`StorageC`。
- `SpecialtaskMgr`、`SpecialTaskC`。
- `LuckyspinMgr`、`LuckySpinC`。
- `BoxpopMgr`、`BoxPopC`。
- `CrazyClickC`。
- `GiftBoxC`、`WeeklyC`。

旧模块源码和资源原则上不删除，只要它们不被启动流程或核心界面引用即可，以降低 Cocos Creator 预制体 UUID 和分包依赖风险。

## 能量行为

能量从核心模式中完全移除；移除：

- `ItemModel`/`ItemMgr` 的能量资源初始化、定时器注册和自动加能量逻辑。
- 合成食物的能量消耗分支和能量不足提示。
- 在线/离线奖励、礼包和广告对能量的发放。
- `ItemC.showBuyEnergyView()` 及购买能量流程。
- `GameC.showBuyEnergyView()`。
- `GameBottomView` 的 CD/能量购买操作。
- `MoneyView` 的能量购买按钮和相关入口。

## 红点和内部事件

需要停止注册和显示面向已删除功能的红点类型，例如任务、商店、建筑、活动、转盘、宝箱和砸蛋红点。

合成必要的内部事件仍保留，例如：

- 棋盘食物增加/删除/移动。
- 顾客订单刷新。
- 金币、代币和经验等保留资源数量变化。
- 等级升级。
- 在线/离线奖励状态。
- 新手引导步骤。

## 验证标准

### 启动验证

- Cocos Creator 2.4.13 可打开工程并完成脚本编译。
- 启动后不显示大厅，直接进入 `GameView`。
- 隐私协议/登录/SDK 初始化仍可执行。
- 不加载已移除功能的分包和 UI。

### 核心玩法验证

- 棋盘可生成、拖动、合成和查看食物。
- 顾客订单可显示、交付和获得金币/经验。
- 等级入口位于左上角，等级奖励可打开和领取。
- 设置入口位于左上角，音乐/音效开关可用。
- 资源 HUD 可显示并随资源变化刷新。
- 界面和运行时均不出现能量资源、能量消耗、能量恢复、能量购买或能量奖励。
- 在线/离线奖励仍可触发并领取。
- 新手引导仍可覆盖核心合成操作。

### 反向验证

- 不显示大厅、家园、建筑、任务、商店、市场、仓库和活动入口。
- 不显示产品红点。
- 不出现能量购买、CD 加速和清除入口。
- 不因移除 `DailyTaskMgr`、`TaskMgr` 或 `StorageMgr` 导致核心合成和顾客订单报错。
