# 游戏内合成链编辑器设计

## 目标

在 Cocos Creator 2.4.13 的核心合成游戏中增加一套游戏内编辑器。玩家可以浏览、创建、查看、修改和删除生成链及链中的合成元素；保存后编辑结果写入本机，并立即被棋盘、生成器、合成、图鉴和相关选择界面使用。

## 当前工程事实

- 游戏启动时从 `assets/resources/data/game_info.json` 加载配置。该文件以 Base64 编码，运行时交给 `XlsxDataManager` 解码。
- 当前静态配置包含 31 条 `FoodTypeModel` 记录和 249 条 `FoodItemModel` 记录。
- `FoodTypeModel` 描述一条分类/生成链，字段为名称、开启等级、权重、状态、旧能量成本和初始生成物 ID。核心玩法不再使用能量成本。
- `FoodItemModel` 描述链内元素，包含名称、稀有度、链 ID、状态、图标、下一阶 ID、缩放、价格、产出类型、产出数组、产出次数、冷却、金币解锁价、分裂概率、等级、售价和旧市场价。核心玩法不再使用市场价。
- 运行时消费者会直接调用 `FoodMgr`、`FoodItemModel`、`FoodTypeModel`、`GridFoodMgr` 等模型，读取链索引、下一阶关系、生成器初始物和产出数组。
- 现有本地存储能覆盖静态表中的部分字段，但 `ModelManager` 的行映射与索引是在初始化时由静态配置建立的，单纯写字段无法新增或删除配置记录。

## 用户入口与操作流程

- 在现有设置面板增加“合成链编辑”入口，保持主棋盘按钮区域简洁。
- 编辑器主界面分为链列表、链详情/编辑和元素列表/编辑三个区域。链列表支持搜索；选中链后列出该链全部元素并支持按等级/ID排序。
- 链编辑支持名称、开启等级、权重、启用状态和初始生成物。删除链前检查棋盘存档及其他链/元素是否仍引用其中元素；存在引用时拒绝删除并提示解除引用。
- 元素编辑支持名称、稀有度、所属链、状态、图标（从当前游戏已有图集帧中选择）、下一阶元素、缩放、价格、产出类型与产出项、产出次数、冷却、金币冷却/解锁价、分裂概率、等级和售价。
- 新建元素从当前链添加；图标从现有图集帧选择，不支持运行时导入图片。新元素的 ID 由编辑器分配，避免与静态和自定义记录冲突。
- 删除元素前检查棋盘格、其他元素的下一阶/产出引用和链初始生成物；有引用时拒绝删除并列出需要先处理的引用。
- 列表点击元素显示只读详情；新增、编辑、删除操作均须保存确认或明确取消。编辑器关闭后返回当前棋盘。

## 数据架构

建立版本化 `MergeChainRepository` 作为可编辑目录的单一读写入口。它以随包静态配置为基础，应用本机保存的覆盖、新增和删除记录，生成运行时合并目录；静态资源本身保持只读。

保存数据使用独立 localStorage 键，包含 schema 版本、自定义 ID 计数、链覆盖/新增/删除集合、元素覆盖/新增/删除集合。自定义链/元素名称保存为直接显示的文本；默认静态名称仍通过现有语言表解析。保存采用先校验后一次写入的方式；无法解析或版本不支持时保留原始值并回退到静态配置，同时向用户显示恢复提示，不静默覆盖数据。

运行时 `FoodMgr` 向所有消费者提供合并后的链/元素查询、按链检索和 ID 查找。编辑器通过 repository 的事务式 CRUD API 改动目录；消费者不直接读编辑器存档。对于静态行和自定义行，模型 getter 使用统一目录值，保持现有调用者接口兼容。

合成链和元素的数字 ID 保持稳定。元素 ID 必须落在当前食物类型编号空间中且不与静态/自定义记录冲突；若编号空间耗尽，新增操作明确失败并提示。链 ID 使用未占用的非负整数。所有引用均使用 ID，不依赖列表显示顺序。

## 产出数据格式

编辑器依 `FoodOutType` 显示匹配的编辑控件，并在保存时编码回现有 `output` 格式：

- `NO_OUT`：不接受产出项。
- `OUT_RANDOM_AND_CD`、`OUT_RANDOM_COUNT_DESTROY`：编辑一组“元素 ID + 权重”对。
- `OUT_ITEM_WITH_OPEN_CD`、`OUT_ITEM_DESTORY`：编辑有序元素 ID 列表。
- `CHOICE_ITEM`：编辑可选元素 ID 列表。
- `OUT_COST_ITEM`：编辑消耗物 ID 与数量。

显示标签和产出元素从运行时合并目录解析。任何产出 ID 不存在或不符合此产出类型要求时阻止保存。

## 校验与删除约束

- 链/元素 ID 唯一，链名称非空；数值字段要求为有限值，且概率/权重、冷却、价格、数量在有效范围。
- `ftype` 必须指向现存链；同链 `nextID` 必须指向同链元素；下一阶关系不能形成循环。
- 每条启用链必须有有效初始生成物；生成器和产出映射必须指向存在的元素。
- 删除不会自动级联清除棋盘或其它配置。存在引用时拒绝删除，并展示引用位置/关系；用户解除引用后可重试。
- 编辑可能改变棋盘已有元素后续合成/生成行为。保存前展示受影响元素和链关系摘要；用户确认后立即应用。

## 重置与恢复

核心游戏已有的“重置数据”操作同时删除本机编辑器存档和普通游戏进度，使静态默认链/元素恢复生效。按先前约定，音乐和音效偏好仍保留。应用启动时若编辑器存档损坏或 schema 版本不兼容，则不应用该存档并提供清晰恢复提示。

## 非目标

- 不在运行时修改 `game_info.json`、安装包资源或工程源文件，也不增加配置导出/导入流程。
- 不支持上传新图片/图集、网络同步、多用户权限或多人协作。
- 不恢复商店、能量、市场等已从核心玩法移除的系统字段。
- 不重构与合成目录无关的游戏数据系统。

## 验收标准

1. 从设置面板可打开和关闭编辑器，编辑过程中棋盘状态不会被意外重置。
2. 可浏览所有默认链和元素，链列表和元素列表与运行时目录一致。
3. 新建、查看、修改、删除链和元素均遵守引用校验；保存后关闭并重新打开游戏，编辑数据仍存在。
4. 修改链初始生成物、元素下一阶和产出映射后，棋盘上后续新生成/合成使用新数据；图鉴及其它通过 `FoodMgr` 查询的界面同步显示。
5. 无效 ID、跨链下一阶、循环关系、无效产出格式和被引用删除都会阻止保存，并给出可理解提示。
6. 执行已有数据重置后，用户编辑恢复静态默认目录；声音设置保持原值。
7. Cocos Creator 2.4.13 能编译和构建目标包；运行时核心路径不存在由新增/删除记录导致的空模型访问。
