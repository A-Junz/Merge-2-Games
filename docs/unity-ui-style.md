# Unity 关卡界面视觉规范

当前 Unity 主界面按参考原型采用竖屏 1080×1920 CanvasScaler 基准：

- 顶部：金币胶囊、蓝色 CASH OUT 高光按钮、等级跳转胶囊。
- 中上部：LEVEL 标题、笑脸进度条与木色重开按钮。
- 中部：木色 ORDERS 牌匾与奶油白订单卡，订单卡使用圆角切片、阴影和高光。
- 订单卡：人物固定在左侧，合成物 Sprite 在右侧纵向排列，支持 1～3 个；未完成只显示图标，完成后在对应图标右下角叠加绿色对号。
- 主体：木质棋盘外框、蓝色 7×8 格子和 10 条食物合成链 Sprite。
- 底部：粉白格纹桌布与橙色 SERVE ITEMS 果冻按钮。
- 左下角：图鉴入口；打开后按 10 条普通合成链展示 80 个等级图标。
- 背景：暖黄色厨房墙、木质柜台、黑板字和绿色叶片装饰。

交互补充：长按棋盘上的合成物 Sprite 区域会弹出删除确认；只有图标区域响应长按，空白格和名称区域不响应。发牌生成 3/4 级元素时，对应格子会播放短暂的 LUCKY 上浮提示。

运行时界面仍由 `GamePresenter` 创建，因此不需要手工拖拽 Prefab；打开主场景并运行即可看到新版布局。`UiFactory` 会优先加载 Unity 内置 UI 背景 Sprite 并使用 Sliced 模式，资源不可用时回退为纯色面板。
